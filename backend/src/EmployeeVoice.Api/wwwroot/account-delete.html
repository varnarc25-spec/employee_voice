Draft page for a public account-deletion route. This is not a government service and not a trade union.

Delete your account

Use this page if you cannot open the Android app. Enter the email on the account. If an account exists, you will receive a confirmation link. The link does not appear on this page, so it is not written into server logs as a query string.

Deleting the account removes the sign-in address, profile, posts, comments, and any organizing-interest record. It does not require you to contact an employer. Organizing interest is not union membership.
